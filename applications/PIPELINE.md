# Pipeline

One row per application. A row is added as **Drafted** and moves to **Applied** only after I confirm I submitted it.

Stages: Drafted → Applied → Screen → Technical → Final → Offer / Rejected / Withdrawn / No reply (after 21 days)

Dates are YYYY-MM-DD. Keep the column names as they are: `scripts/pipeline.py` reads this table. To view it, type `pipeline` or run `python3 scripts/pipeline.py --open`.
