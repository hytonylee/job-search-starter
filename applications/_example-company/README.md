# What goes in a company folder

Created by `apply: [company]`. Delete this example folder once you have a real one.

- `posting.md`: the full posting text, pasted the day you apply. Postings get taken down
- `fit.md`: each required item, whether I meet it, and the evidence
- `resume.md`: the tailored version sent to this company
- `cover-note.md`: if one was sent
- `research.md`: written by `research`. What the company does, recent news, questions to ask, with sources
- `interview-notes.md`: written by `debrief`. Every question I remember, and how I answered
- `contacts.md`: who I spoke to, when, and what they said about next steps
