# Example data

A fictional candidate, Sam Rivera, about seven weeks into a product management job search. The dashboard shows this folder when you press **See an example**, so you can see what a working project looks like before yours has anything in it.

Everything here is invented: the person, the employers, the companies and the numbers. Nothing in this folder is read by your AI tool or mixed with your own files. `today.txt` pins the date the example is viewed "as of", so its overdue flags stay the same.

You can delete this folder. The button then disappears.
