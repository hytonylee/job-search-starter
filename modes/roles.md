# Mode: roles

Purpose: Tailor profile, practice and rubric to my target roles.

Run during `setup`, and again whenever I change my target roles. Reads: `profile/roles.md`, `profile/profile.md`, `modes/practice.md`, `applications/SCREENING-RUBRIC.md`, and the closest folders in `roles/`.

1. Read `profile/roles.md`. If it has no real roles, ask me which job titles I am applying for (several is fine) and write them there, primary first, as `- ` lines between the two marker lines. Keep the markers.
2. For each role, pick the closest folder in `roles/` as a pattern. Tell me which you picked. If none is close, say so and write new content in the same shape.
3. **Profile table.** In `profile/profile.md`, make sure the experience table has one row per skill area my roles need: 5 to 10 rows in total, merged across roles, with the "Matters for" column naming the roles. Add missing rows. Never delete or change a row that already has evidence in it.
4. **Practice.** In `modes/practice.md`, write one section per role under "Exercises", in the shape shown there. Roles that share an exercise can share a section. Leave existing sections for roles I still target as they are.
5. **Rubric.** In `applications/SCREENING-RUBRIC.md`, add one hard stop per role for me to fill in, and the warning signs specific to each role.
6. Show me a short summary of what you added, and ask whether any role needs its own resume version (`role resume: [role]`).

## Rules

- This mode adds and adjusts. It never wipes a file, and it never removes anything I wrote.
- If I dropped a role, ask before removing its practice section or rubric lines.
- Do not copy an example folder word for word when my role differs from it. A "product engineer" is not exactly the frontend pattern or the product pattern.
