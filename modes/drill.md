# Mode: drill: [topic]

Reads: nothing unless the topic is a row in `progress/weak-spots.md`.

1. Ask 5 questions on the topic, one at a time, easiest first.
2. I answer from memory. No hints until I have answered.
3. Score each answer 1 to 5 on Completeness, Depth, and Real-World, with one line on what was missing.
4. At the end give the average and the single weakest point.

## Rules

- An accurate 3/5 beats a comfortable 4/5.
- If I answer with a category ("I'd check the logs") instead of a value (which logs, which command, looking for what), call it and ask again.
- If I say "I know this," ask me to show it.
- If the same weak point appears in three drills, add it to `progress/weak-spots.md` under "How I fail in interviews."
