# Mode: stories

Shows which interview questions I have a story for. Reads: nothing. Run the script instead of opening the story files.

1. Run `python3 scripts/stories.py` and show me the output as is.
2. For each question with no story, ask whether something in "Strongest evidence" in `profile/profile.md` could answer it. Do not invent a candidate story.
3. For each flagged story, say the fix in one line.
4. Recommend the single most useful next step: usually the missing question most likely to come up for my primary role, then `story` to build it.

Before an interview, I can read all the stories on the dashboard's Prep tab.
