`practice`, or `practice: [role]`. Reads: `profile/roles.md`, `profile/profile.md` (to stay inside what I claim).

1. If I have more than one target role and did not name one, ask which.
2. Find that role's section under "Exercises" below. If there is none, run `roles` first to write it.
3. Run the exercise exactly as its section says.
4. Add a row to `progress/practice-log.md`: today's date as YYYY-MM-DD, `practice`, the role and topic, the average score out of 5 as a number, and the weakest point in a few words.

## Rules for every exercise

- I do the work. You never do it for me, and you never rewrite my answer into a better one.
- Do not suggest the next step. Silence is fine.
- If the result is right but I cannot explain why, score it as a fail.
- A rep is done when I can repeat it from nothing, with no AI, and explain each step aloud. Reading and watching never count.
