# Mode: debrief: [company]

Run within an hour of any real screen or interview. Reads: `applications/[company]/`.

1. Ask me to recall every question I was asked, in order. Prompt "what came next?" until I run out.
2. For each, ask how I answered and how it landed.
3. Write it all to `applications/[company]/interview-notes.md` with the date and interviewer.
4. Record names and stated next steps in `contacts.md`.
5. For each question I answered badly, add or raise a row in `progress/weak-spots.md`.
6. Update the stage, last contact and next action in `applications/PIPELINE.md`.
7. Draft a thank-you note only if I ask.
