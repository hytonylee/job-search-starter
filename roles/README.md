# Example role patterns

Reference material for the `roles` keyword. Each folder shows what good role-specific content looks like for one kind of job: the skill areas for the profile table, a live practice exercise, and screening signals.

Nobody picks from this list. A user types their own target roles, and the AI uses the closest folder here as a pattern, adapting it to the roles they typed. If nothing here is close, the AI writes new content in the same shape.

To improve the starting point for a kind of role, edit its folder or add a new one with the same three files.
