# Interview stories

One file per story, in STAR form: Situation, Task, Action, Result. Build them with the `story` keyword, which asks the questions and writes the file. See coverage with `stories`.

These are notes to speak from, not scripts to memorise. Each file holds the facts and the result; the practice is saying it aloud in about two minutes.

Every claim in a story must be backed by `profile/profile.md`.
